# Ranger Match

Quiz practice for Grade 7 word study, Interactions in the Environment. Twenty-one words, three short missions.

Open `index.html` in a browser. The best score stays in that browser.

To put it on the web after you push, turn on GitHub Pages for the `main` branch and the root folder. The page will be at `https://jaymon0703.github.io/environment-word-match/`.

# Vive les Sports

French Unité 1, in `french.html`. Thirty-five words, six short missions. Open it the same way. Hear it uses the Canadian French voice on this Mac.

On GitHub Pages the French game will be at `https://jaymon0703.github.io/environment-word-match/french.html`.

# Long division

Digit-by-digit practice, in `division.html`. Drag each number into the worksheet. A wrong drop costs 5 points.

On GitHub Pages it will be at `https://jaymon0703.github.io/environment-word-match/division.html`.
